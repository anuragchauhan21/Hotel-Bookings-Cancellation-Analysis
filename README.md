# Hotel Booking Cancellation Analysis

## Overview  
This project analyses hotel booking data to understand cancellation behaviour, booking patterns, and key operational drivers. The objective is to identify measurable factors influencing cancellations and support data-driven decision making for revenue and occupancy optimization.

## Problem Statement  
Booking cancellations impact hotel revenue, forecasting accuracy, and resource planning. This analysis aims to quantify cancellation patterns and identify key segments contributing to booking instability.

## Dataset  
- Total Records: 119,390  
- Total Features: 32  
- Data includes booking details, customer information, and reservation status  

## Approach  

### Data Preparation  
- Cleaned missing values and handled inconsistent data formats  
- Converted reservation dates to datetime for time-based analysis  
- Processed categorical and numerical variables for analysis  

### Exploratory Data Analysis  
- Analysed cancellation distribution across hotel types  
- Studied booking behaviour across market segments  
- Evaluated temporal trends in reservations and cancellations  
- Compared pricing trends between canceled and non-canceled bookings  

## Key Insights  

- City Hotel cancellation rate: 41.71 percent vs Resort Hotel: 27.98 percent  
- Online Travel Agencies contribute 46.97 percent of total bookings  
- Groups and Offline TA/TO segments contribute 27.40 percent and 18.75 percent respectively  
- Top 10 countries account for the majority of total cancellations  
- Booking cancellations vary significantly across months, indicating seasonal patterns  
- Average Daily Rate shows distinct trends between canceled and non-canceled bookings

## Business Impact
